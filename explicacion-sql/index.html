🗄️ ¿Qué es una Base de Datos? 🗣️

Aprendé el idioma que usan las computadoras para guardar y buscar información: el SQL

Imaginate una base de datos como un armario gigante lleno de carpetas bien ordenadas. El SQL es el idioma que usamos para pedirle cosas a ese armario, como "mostrame todas las carpetas de color rojo" o "agregá una carpeta nueva".
